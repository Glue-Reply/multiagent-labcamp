# A2A Protocol — Agent-to-Agent Communication

## Step 1 — Install the A2A extras

```bash
pip install google-adk[a2a]
```

---

## Step 2 — Build the remote agent to expose

Create the agent you want to make available to others (`remote_a2a/my_service/agent.py`):

```python
from google.adk.agents.llm_agent import Agent
from google.adk.a2a.utils.agent_to_a2a import to_a2a

def check_prime(nums: list[int]) -> dict:
    """Returns whether each number in the list is prime."""
    def is_prime(n):
        if n < 2:
            return False
        for i in range(2, int(n**0.5) + 1):
            if n % i == 0:
                return False
        return True
    return {str(n): is_prime(n) for n in nums}
```

> **Task:** Create an `LlmAgent` as you learned earlier and plug `check_prime` into it as a tool. Name it `prime_agent`. Once you have it, expose it as an A2A app using `to_a2a()` on port `8001`.

```python
# Expose the agent as an A2A server on port 8001
# to_a2a() auto-generates the agent card
a2a_app = to_a2a(root_agent, port=8001)
```

---

## Step 3 — Start the remote agent server

```bash
uvicorn remote_a2a.my_service.agent:a2a_app --host localhost --port 8001
```

Verify the agent card is accessible:

```
http://localhost:8001/.well-known/agent-card.json
```

---

## Step 4 — Consume the remote agent

> **Task:** In your main `agent.py`, use `RemoteA2aAgent` to create a client-side proxy that points to the `prime_agent` running on `http://localhost:8001`. Then create a new `LlmAgent` called `root_agent` that uses it as a `sub_agent` and delegates prime-checking tasks to it.

---

## Step 5 — Run the consuming agent

```bash
# Terminal 1 — remote agent (must already be running from Step 4)
uvicorn remote_a2a.my_service.agent:a2a_app --host localhost --port 8001

# Terminal 2 — consuming agent web UI (run from the parent folder)
adk web --port 8000
```

Open http://localhost:8000, select `root_agent`, and start chatting.

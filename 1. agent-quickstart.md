# ADK Python Quickstart

A basic setup guide for building agents with [Agent Development Kit (ADK)](https://adk.dev/get-started/python/).

**Prerequisites:** Python 3.10+, `pip`

> **Windows users:** use **PowerShell** for all commands in this guide.

---

## 1. Install Google Cloud CLI

Download and run the installer from [cloud.google.com/sdk/docs/install](https://cloud.google.com/sdk/docs/install). Select the **Windows** tab and download the `.exe` installer.

After installation, open a **new** PowerShell window. If you see this error when running `gcloud`:

```
File cannot be loaded because running scripts is disabled on this system.
```

Run the following to allow scripts, then reopen PowerShell:

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

Verify the install:

```bash
gcloud --version
```

---

## 2. Authenticate with Google Cloud

Sign in with your Google account:

```bash
gcloud auth application-default login
```

Set the shared project for Vertex AI quota:

```bash
gcloud auth application-default set-quota-project active-dahlia-409122
```

---

## 3. Installation

Create and activate a virtual environment:

```powershell
python -m venv .venv
# macOS/Linux:
source .venv/bin/activate
# Windows (PowerShell):
.venv\Scripts\Activate.ps1
```

Install ADK:

```bash
pip install google-adk
```

---

## 4. Create an Agent Project

```bash
adk create my_agent
```

When prompted:
- **Model:** `gemini-2.5-flash`
- **Backend:** Vertex AI
- **Project ID:** `active-dahlia-409122`
- **Region:** `europe-west2`

This generates the following structure:

```
my_agent/
    agent.py      # main agent code
    .env          # project config
    __init__.py
```

---

## 5. Update the Agent

Replace the contents of `my_agent/agent.py`:

```python
from google.adk.agents.llm_agent import LlmAgent

def get_current_time(city: str) -> dict:
    """Returns the current time in a specified city."""
    return {"status": "success", "city": city, "time": "10:30 AM"}

root_agent = LlmAgent(
    model='gemini-2.5-flash',
    name='root_agent',
    description="Tells the current time in a specified city.",
    instruction="You are a helpful assistant that tells the current time in cities. Use the 'get_current_time' tool for this purpose.",
    tools=[get_current_time],
)
```

---

## 6. Run Your Agent

```bash
adk web --port 8000
```

Access the web interface at http://localhost:8000.

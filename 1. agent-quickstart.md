# ADK Python Quickstart

A basic setup guide for building agents with [Agent Development Kit (ADK)](https://adk.dev/get-started/python/).

**Prerequisites:** Python 3.10+, `pip`, [Google Cloud CLI (`gcloud`)](https://cloud.google.com/sdk/docs/install)

---

## 1. Authenticate with Google Cloud

Sign in with your Google account:

```bash
gcloud auth application-default login
```

Set the shared project for Vertex AI quota:

```bash
gcloud auth application-default set-quota-project active-dahlia-409122
```

---

## 2. Installation

Create and activate a virtual environment:

```bash
python3 -m venv .venv
# macOS/Linux:
source .venv/bin/activate
# Windows:
.venv\Scripts\activate
```

Install ADK:

```bash
pip install google-adk
```

---

## 3. Create an Agent Project

```bash
adk create my_agent
```

When prompted:
- **Model:** `gemini-2.5-flash`
- **Backend:** Vertex AI
- **Project ID:** `active-dahlia-409122`
- **Region:** `europe-west2`

This generates the following structure:

```
my_agent/
    agent.py      # main agent code
    .env          # project config
    __init__.py
```

---

## 4. Update the Agent

Replace the contents of `my_agent/agent.py`:

```python
from google.adk.agents.llm_agent import LlmAgent

def get_current_time(city: str) -> dict:
    """Returns the current time in a specified city."""
    return {"status": "success", "city": city, "time": "10:30 AM"}

root_agent = LlmAgent(
    model='gemini-2.5-flash',
    name='root_agent',
    description="Tells the current time in a specified city.",
    instruction="You are a helpful assistant that tells the current time in cities. Use the 'get_current_time' tool for this purpose.",
    tools=[get_current_time],
)
```

---

## 5. Run Your Agent

```bash
cd ..
adk web --port 8000
```

Access the web interface at http://localhost:8000.
